# Licensing model

- **Core app:** AGPL-3.0-or-later. Anyone, including any chamber, can use, study, modify and
  share it. Anyone who distributes the app, or runs a modified version as a network service, must
  publish their source code under the same license. This prevents closed forks.
- **CLA:** contributors keep their copyright and grant the maintainer the right to relicense.
  This lets the maintainer offer the same code under other terms.
- **Commercial options this enables:**
  - Paid installation, training and support contracts
  - A hosted version run by the maintainer
  - Commercial licenses for organizations that cannot accept the AGPL
  - Closed "Pro" modules. These contain only code that the maintainer owns or that is
    covered by the CLA, and only dependencies that allow it
    (see [dependency-licenses.md](dependency-licenses.md)).
