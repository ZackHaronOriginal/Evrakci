# Plan 7: Linux build

Owner's request (2026-11-09): "Could we have a Linux build as well?"

**Goal:** a portable Linux folder build (`evrakci-<sürüm>-linux-x86_64.tar.gz`) with the same
two programs as Windows (`evrakci`, `evrakci-arayuz`), built and tested on a GitHub Actions
Linux runner, with a per-user install script that needs no root.

## Decisions

- **Same freeze as Windows.** cx_Freeze folder build (`packaging/build.py`); Qt stays as separate
  shared libraries in the folder, so it is replaceable (LGPL), as on Windows.
- **Tesseract comes from the distribution** (`sudo apt install tesseract-ocr`), not bundled.
  Tesseract's shared libraries (Leptonica, libpng, libtiff, libarchive…) differ per distribution;
  a copied set breaks on the next one. Every Debian/Ubuntu/Pardus/Fedora ships Tesseract.
- **tur_best is bundled** (checked against the pinned SHA-256), with Tesseract's `configs` and
  `tessconfigs` copied in at build time (`--tessdata-configs`), because the install folder may be
  read-only. The system's own `tur` package is not needed.
- **Built on ubuntu-22.04** (glibc 2.35), so it runs on Ubuntu 22.04+, Debian 12 and Pardus 23.
- **Install:** `./kur.sh` copies the folder to `~/.local/share/evrakci`, links both programs
  into `~/.local/bin` and adds a menu entry (`~/.local/share/applications/evrakci.desktop`).
  `./kaldir.sh` removes exactly those; jobs and templates stay. Both say (in Turkish) when
  Tesseract or Qt's `libxcb-cursor0` is missing.
- **patchelf** is a build-time tool only (GPL-3.0, not shipped), like Inno Setup on Windows.

## Tasks (TDD: each test fails first)

1. `build.py --tessdata-configs DIR`: copies `configs`/`tessconfigs` into `tessdata_best`;
   refuses a folder without `configs/hocr`.
2. `packaging/linux_package.py`: tarball with one top folder `evrakci-<sürüm>/`, executable
   `kur.sh`, `kaldir.sh` and programs, a `.desktop` template.
3. `kur.sh` / `kaldir.sh`: tested by running them with a temporary `HOME`, from a folder with
   Turkish letters and spaces.
4. Workflow `.github/workflows/linux-build.yml`: tests, freeze, start the window, remove the
   system `tur` data and smoke-test (proves the bundled tur_best is used), install with
   `kur.sh` into a temporary HOME and smoke-test the installed copy, upload the tarball.
5. Docs: README, `docs/dependency-licenses.md`, NOTICE, progress.

Then a fresh whole-diff review, every finding fixed with a failing test first.
