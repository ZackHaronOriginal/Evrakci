# Değerler audit: findings

Phase 4, Görev A, screen Değerler. Audit date 2026-11-19, working tree at HEAD a5c1d97 (no uncommitted change under `src/` while auditing; other agents' parallel edits in `tests/` are ignored; no code changed here).
Every failing `rules.json` rule and every failed click path is a row. The run lead merges these into `bugs.md`; this file does not edit it. Existing ledger rows are named in the last column
so nothing is merged twice.

Severity: S1 data loss / silent wrong output / no keyboard path; S2 unusable in a supported theme or size; S3 visible, workable; S4 polish. None of the rules is enforced yet (owner Q-03), so rule
failures are reported only. Two rows use S2 for a flow that is broken, not unreadable (F-degerler-01 the N key, F-degerler-03 the double click): there is a keyboard path and an undo, so they are not S1; the
run lead may regrade.

Evidence names: `P-nnn` is a row in `degerler-paths.md`; `S:<NN>-<name>` is a PNG in `/tmp/claude-0/p4/degerler/states/<theme>-<NN>-<name>.png`; `S:L<n>-...` the long-content shots there; `M` is
`/tmp/claude-0/p4/degerler/measure.tsv` (`python tools/ui_measure.py --tab degerler`, 3 themes x 2 sizes x 2 text sizes, 4,833 rows: 4,694 pass, 76 fail, 63 skip); `long-facts` is
`/tmp/claude-0/p4/degerler/long-facts.tsv`; `motion.log` is `/tmp/claude-0/p4/degerler/motion.log`; `cols.tsv` is `/tmp/claude-0/p4/degerler/cols.tsv`. Scripts are in the session scratchpad and

## Not checked, and limits
