# Dışa Aktar audit: copy

Phase 4, Görev A, screen Dışa Aktar. Every Turkish string on the screen, checked for clarity, correctness, and consistency with the vocabulary Kontrol / Emin / Orta / Kontrol / Okunamadı / İncelendi / İncelenmedi, and for errors that say what to do next. On this screen only Kontrol and Emin (as "emin olunmayan") occur; Orta, Okunamadı, İncelendi and İncelenmedi do not appear (the tab does not read Kontrol's İncelendi approvals: research obs. 17). Findings only; proposed rewrites would be new Turkish text and go to the owner (`disa-aktar-proposals.md` is written in step B).

Verdicts: ok / unclear / inconsistent / no next step. "Next step" is judged for messages that report a refusal or an error. Findings reference `disa-aktar-findings.md`. Turkish was read by the auditor; a native-speaker check by the owner is still needed for tone (not done). Pure style strings (object names, icon names) and the Windows-only Explorer text are not rows. Strings were collected from `disa_aktar*.py`, `pipeline/exporting.py`, `main_window.py`, `actions.py` and the accessible names printed by keywalk.
