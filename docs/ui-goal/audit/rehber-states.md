# Rehber audit: state matrix

Phase 4, Görev A, screen Rehber. Rows are elements or groups from `rehber-inventory.md` (E-ids). Columns are the states from the phase plan. Every cell is one of: a screenshot reference (`S:<name>`, a PNG in `/tmp/claude-0/p4/rehber/states/`, or `S:matrix <name>` for a file in `/tmp/claude-0/p4/rehber/matrix/`), a path row (`P-nnn` in `rehber-paths.md`), a measured row (`M:`), a fact from the long-content runs (`L:`), `GAP:` (not shot, with the reason) or `n/a: <reason>`.

How the cells were made (all offscreen, synthetic data, window 1366x768, light 100 % unless the name says otherwise): windows built fresh in each theme and text size by `tools/screenshots.py:build` with the custom title band forced (no runtime theme switching for the shots), states put in with small QTest scripts (`s1.py`, `p5.py`, `p6.py`, `p7.py` in the session scratchpad). Hover and pressed were made with `QTest.mouseMove` and `QTest.mousePress`: the primary button and the contents row show them; the command-bar buttons and the small chevron and x buttons show no hover change offscreen (the shots are pixel-identical to the rest state), so those cells say GAP and are not claimed as missing in the product. The three file names `light`, `dark`, `hc` in a name are the theme; `100` and `150` the text size. Measured rows come from `python tools/ui_measure.py --tab rehber` (3 themes x 2 sizes x 2 text sizes) in `/tmp/claude-0/p4/rehber/measure.tsv`: 3,375 rows, 3,210 pass, 63 fail, 102 skip. Failing rules: AUD-HIT-02 36 (search x 12: F-rehber-14, zoom buttons 24: F-rehber-15), AUD-HIT-01 12 (search x: F-rehber-14), AUD-WIN-02 9 (the guide's scroll bar: F-rehber-16), DEC-FOC-01 6 (title tabs, a tool artefact: F-rehber-29). Every other rule passes for every Rehber widget: type floor and ramp (DEC-TYP-01 to -03, 252 rows each), text contrast (DEC-CON-01 89 pass, DEC-CON-02 130 pass, 33 skipped as unmeasurable), accessible names (AUD-A11Y-01 216 pass), keyboard reach (AUD-KBD-01 192 pass, 48 skipped: the window's caption buttons and the field's clear action), spacing and radii (DEC-LAY-01 to -03 all pass), icon size (DEC-ICO-01 180 pass).
