Every failing `rules.json` rule and every failed click path is a row. The run lead merges these into `bugs.md`; this file does not edit it. Existing ledger rows are named in the last column so nothing is merged twice.

Severity: S1 data loss / silent wrong output / no keyboard path; S2 unusable in a supported theme or size; S3 visible, workable; S4 polish.
