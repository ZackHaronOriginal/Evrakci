# Şablonlar audit: state matrix

Phase 4, Görev A, screen Şablonlar. Rows are elements or groups from `sablonlar-inventory.md` (E-ids). Columns are the states from the phase plan. Every cell is one of: a screenshot reference (`S:<name>`), a path row (`P-nnn` in `sablonlar-paths.md`), a measured row (`M:`), a fact from the long-content runs (`L:`), or `n/a: reason`. A cell that could not be filled says `GAP: reason` instead of a guess; the gaps are counted at the end.

How the cells were made (all offscreen, synthetic data, window 1366x768, light 100 % unless the name says otherwise): `screenshots.py` windows built fresh in each theme and text size (`make` in the session scratchpad, no runtime theme switching, the app configured as `screenshots.py` does: custom frame, fonts, style sheet), driven with QTest and direct calls on `SablonScreen`. Screenshot files are `/tmp/claude-0/p4/sablonlar/states/<tag>-<name>.png`; the tag is the theme and text size (`light100`, `dark150`, `hc100`, `hc150`; the L runs also exist as `hc100`, the K and M runs as `light100` and `dark150`, J as `light100`, `light150`, `hc130`). Names: A1 no template and no job; B1 template, no box; B2 two boxes; B3 box chosen; B4 Kutu çiz on; B5 readings shown; B6 red message; B7 pattern error; B8 "Okunuyor…"; B9 canvas focus; B10 hover and B11 focus on Kutu çiz; E1 template without job; E2 job without template; E3 template without variable; E4/E4b example file missing; E5/E5b 151 documents; G-level-* the four levels; H-* hover, focus and pressed; J nothing chosen; K-long-read-* long reads; L1..L9 the long template (open, variable chosen, section 3, nav scrolled, 31 sections, section 26, try-all, delete toast); M-long-* long message and job name.
