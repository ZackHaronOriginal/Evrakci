# Phase 1 mockups: review round 1

Three independent reviews (ui-review, design-critique, accessibility) found 57 issues: 7 high,
31 medium and 19 low. This table lists each one and what was done with it. Everything was re-rendered
with `python3 _render.py`, which covers light, dark, the HC preview for Kontrol and Değerler, and
150 % text for every tab. The result was 0 clipping or layout warnings. `python3 _contrast.py` was
re-run on `tokens.css` and reported 0 failing pairs in light, dark and HC.

Several findings name the same problem, so the table cross-references them. "README" means
`README.md` in this folder: it now holds the rules every tab follows ("Rules applied on every tab"),
the shared status vocabulary ("Durum sözlüğü") and the shortcut changes against 07-qol-audit §3.

## Also fixed this round

- **Değerler table:** at 100 % text it scrolled sideways by 26 px and cut the Güven column ("Kontrol %5…"). The cause was that `table-layout: fixed` with `width: auto` ignores column widths. The table now uses `width: max(100%, 960 px × text-scale)` with reworked column widths, and the inspector is 352 px wide. To catch this kind of problem, `_render.py` now warns about any sideways scroll at 100 % text. The only exemption is the loupe filmstrip, which scrolls by design and is marked `data-clip-ok`.
- **Rehber empty state:** it had two filled primaries (Aramayı temizle + Yazdır). "Aramayı temizle" is now secondary, and its Esc key moved to the tooltip.
