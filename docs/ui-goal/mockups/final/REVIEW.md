# Round-3 review: findings and fixes

Two reviewers (`visual`, `a11y-ux`) reviewed the final direction-A spec. Every high and medium
finding is fixed, and so is every low. Checks after the fixes: `python3 _contrast.py --write` gives
0 failing pairs in light, dark and five HC palettes. `python3 _render.py --sheets` gives 0 warnings
over 23 states × (light, 130 %, 150 %), with the new overlap and stale-sheet checks. All 121 renders
and the 23 regenerated contact sheets were opened and checked by eye.

## Noticed but not changed

- At 150 % the wider inspector brings Kontrol's page share to 47.2 % (gate 7 is defined at the
  default text size). Hiding the inspector restores it. README §5 records this.
- In Değerler at 130 % and 150 %, the toast pushes the Değer card below the inspector's fold while it shows. It
  covers nothing, and the scroll cue shows there is more below.
- `src/evrakci/ui/actions.py` and `docs/ui-goal/shortcuts.md` are outside this folder. The key-name
  map, an optional panel-toggle key and the Ctrl+S wording are listed for the build in README §11.
