# Findings: naming and export formats (5c, R5c-3)

Researched 2026-11-19 at commit 89c4844. Research for ideas only; nothing here is a decision. Nothing was copied from any project; all text is paraphrase. "We do" cites our inventory ([inventory-disa-aktar.md](inventory-disa-aktar.md), IDs D-xx). Every external claim has a link to a page that was opened. ## What we do (from the inventory)
- Pattern with `{variables}`, per-job override held only in memory (D-18, D-19, D-20, Observation 3). Name rules in one function: forbidden Windows characters deleted, NFC, whitespace folded, doubled separators collapsed, 120 character cap, device names guarded, clashes get " (2)", path kept under 250 UTF-16 units (D-21). Numbered fallback `belge_NNN` (D-22). Live "Örnek:" preview and a name list before writing (D-20, D-27). One PDF per document, PDF/A-2b with text layer by default, fallback to plain searchable PDF flagged (D-24, D-41, D-42). `index.xlsx` always written (D-25, D-43 to D-45).

## Ideas for the owner's ranking
1. **Save the name pattern with the job.** Problem: a window export can name files differently from the CLI after a restart (D-18, Obs. 3). Who gains: staff re-opening a job; CLI users. Evidence: Paperless keeps patterns as saved objects ([docs](https://github.com/paperless-ngx/paperless-ngx/blob/dev/docs/advanced_usage.md)). Effort S to M.
2. **Make the PDF/A-failed state agree in list, card and index.** Problem: card says "N kontrol" while list shows none (Obs. 1). Who gains: everyone reading the outcome. Evidence: OCRmyPDF treats a not-checked file as failed and says so ([cookbook](https://ocrmypdf.readthedocs.io/en/latest/cookbook.html)). Effort S.
3. **Add "Belge no", job name and export time to index.xlsx.** Problem: rows cannot be tied to numbered names (Obs. 10). Who gains: staff reconciling the sheet with the folder. Evidence: Kofax logs each export per document ([manual](https://www.manualsdir.com/manuals/658182/kofax-capture.html?page=8)). Effort S.
4. **Decide delete vs replace for forbidden characters, and fix the checkbox label.** Problem: label says "değiştir", rule deletes (Obs. 9). Evidence: Paperless replaces, we delete ([docs](https://github.com/paperless-ngx/paperless-ngx/blob/dev/docs/advanced_usage.md)). Effort S. Visible change, so owner decides.
5. **Check the long-path opt-in for the Windows build.** Problem: deep network folders shorten names. Evidence: [Microsoft](https://learn.microsoft.com/en-us/windows/win32/fileio/maximum-file-path-limitation). Effort S to check, M to ship.
