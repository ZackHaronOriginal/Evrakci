# Findings: region reading (OCR of a drawn box)

Research for ideas only (5c). Nothing here is a decision. Written 2026-11-19. Our side: `inventory-sablonlar.md` (S-), `inventory-degerler.md` (V-) and code at HEAD ab7a87d: `src/evrakci/pipeline/ocr/tesseract.py`, `ocr/engine.py`, `ocr/preprocess.py`, `templates/read.py`. External facts are paraphrased, each followed by the page that was opened.

## What we do today (from code)

- A box is cut from the page image (rendered at 300 dpi) and handed to Tesseract with page segmentation mode 6, "one uniform block of text", `--dpi 300`, TSV output, one thread (`tesseract.py:395-437`, `read_region` at 436-437).
- The text of all words is joined; the reading's confidence is the plain mean of the word confidences (`ocr/engine.py:44-48`).
- No padding, upscaling, binarising, deskew, character whitelist or dictionary switch in the live path. `prepare_region` (deskew plus Otsu) exists but is called only from the comparison harness and the CLI (`ocr/compare.py:60`, `cli/ocr.py:222`; grep of the whole `src/`).
- Variants are tried top to bottom; the first one at or above the template threshold wins; otherwise all readings are kept and the best becomes the suggestion (`templates/read.py`, V-05, V-62).
- Rotation the user set in Kontrol is applied before cutting (V-07). A box outside the page, or a missing page, is recorded as a reason (V-06, S-56).

## Ideas for the owner's ranking

1. **Measure padding, psm 7 and preprocess with the existing comparison harness before changing anything.** Problem: live reads use none of the standard small-crop advice. Who gains: everyone who reads values; fewer Kontrol flags. Evidence: [Tesseract ImproveQuality](https://tesseract-ocr.github.io/tessdoc/ImproveQuality.html). Effort: S (measure), S (switch on if it wins).
2. **Try the weakest word as the flag score.** Problem: a mean can hide one bad word. Evidence: [ACL NLP4DH 2023](https://aclanthology.org/2023.nlp4dh-1.20.pdf) (describes the legacy rule only). Effort: S, harness first.
3. **Optional per-variable "what it contains" hint** (digits only, single line) that sets psm and character set. Problem: no type today (S-17). Evidence: [ImproveQuality](https://tesseract-ocr.github.io/tessdoc/ImproveQuality.html), [DocuWare](https://knowledgecenter.docuware.com/docs/processing-documents). Effort: M. Fits "users name their own variables" only if optional.
4. **Read all variants and offer the most confident.** Evidence: [Kofax index zone](https://docshield.tungstenautomation.com/KC/en_US/11.1.0-40hy9nfk91/help/main/KC_administration/c_indexgrpzonepropgen.html). Effort: M; costs read time.
5. **"Re-read this value from a box I draw" in Değerler.** Evidence: [Kofax Rubber Band OCR](https://docshield.tungstenautomation.com/KC/en_US/11.1.0-40hy9nfk91/help/main/KC_validation/t_rubberband_ocr.html). Effort: M.
6. **Snap-to-word box drawing in Şablonlar.** Evidence: same Kofax page (single-click capture). Effort: M.
7. **Per-variable replace list.** Evidence: [DocuWare](https://knowledgecenter.docuware.com/docs/processing-documents), [invoice2data source](https://github.com/invoice-x/invoice2data/blob/master/src/invoice2data/extract/invoice_template.py). Effort: M.
