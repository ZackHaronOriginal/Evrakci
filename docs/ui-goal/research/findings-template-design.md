# Findings: template design (Şablonlar)

Research for ideas only (5c). Nothing here is a decision. Written 2026-11-19. Our side: `inventory-sablonlar.md` (S-) and `inventory-degerler.md` (V-), code at HEAD ab7a87d (`src/evrakci/pipeline/templates/model.py`, `read.py`). External facts are paraphrased with the page that was opened. No commercial or GPL source was read; the one open-source project read for implementation is invoice2data (MIT).

## What we do today

- Template = named variables, each with one or more sections (page, box in mm, optional label of the example it came from) tried in order; file-name pattern with `{Variable}`; threshold default 0.70; keywords; Zorunlu flag (S-10, S-12 to S-16, S-22, S-23, S-31).
- Draw on a real example page of the open job: drag or keyboard, grid snap, mm rulers, nudge and resize by key, copy box, per-box read cards, live read, "try on all examples" (S-39 to S-58).
- One JSON file per template, import and export in the core, autosave, own undo (S-04, S-06, S-08, S-68). No types or checks (S-17). No rename or delete of a template in the window (S-09).
- Variants: add from Değerler with a hand-off that lands on page 1 (S-30, O-07, O-08 in the Değerler inventory).

## Ideas for the owner's ranking

1. **Fix the variant hand-off page** (O-08) and carry the document from Değerler (O-09). Problem: a variable whose box is on page 2 opens on page 1. Who gains: reviewers fixing a variant. Evidence: internal. Effort: S.
2. **Cross-example "weakest first" list in Şablonlar.** Problem: after "dene" only a count shows (S-58); the user wants to see which examples fail. Evidence: [Kofax Zone Test](https://docshield.tungstenautomation.com/KC/en_US/11.1.0-40hy9nfk91/help/main/KC_administration/c_zonetest.html) shows a result line per image. Effort: S.
3. **Try a template on a PDF that is not in the job.** Problem: S-37. Evidence: [Kofax Zone Test](https://docshield.tungstenautomation.com/KC/en_US/11.1.0-40hy9nfk91/help/main/KC_administration/c_zonetest.html), CLI exists (S-62). Effort: M. Privacy rule: nothing stored.
4. **Snap a box to a word on click.** Evidence: [Kofax Rubber Band OCR](https://docshield.tungstenautomation.com/KC/en_US/11.1.0-40hy9nfk91/help/main/KC_validation/t_rubberband_ocr.html). Effort: M.
5. **Optional fixed value and replace list per variable.** Evidence: [invoice2data README](https://github.com/invoice-x/invoice2data), [DocuWare](https://knowledgecenter.docuware.com/docs/processing-documents). Effort: M.
6. **Template rename and delete in the window.** Problem: S-09, plus silent empty names. Evidence: internal. Effort: S.
7. **Later/maybe: mark-present zone.** Evidence: [OnBase](https://docs.hyland.com/r/OnBase/Advanced-Capture/Foundation-23.1/Advanced-Capture/Configuration/Configuring-Advanced-Capture/Configuring-Advanced-Capture-Forms/Configuring-A-Data-Field-Zone). Effort: L. Need unproven.
