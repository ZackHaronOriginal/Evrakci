# Feature inventory: the Kontrol tab

Scope: everything a user can see, press, select or read on the Kontrol tab of Evrakçı, plus the core
functions it calls (`src/evrakci/pipeline/cuts.py`, `job.py`, `export.py`, `analyze.py`) and the
controller (`src/evrakci/ui/controller.py`).

How this was made: every row was read from the code. Tests were read, not run. Where code and test
could not settle a point, the row says "unclear" and why. Nothing here is a decision; the Observations at
the end are things noticed, each marked as an observation.

Conventions
- Paths are under `src/evrakci/` unless they start with `tests/`. `ui/kontrol.py:toggle_cut (L317)` means
  function and line in the file as read.
- "Tested?" names a file in `tests/ui/` (or `tests/`) and the test. "none" means no test found by reading
  the test files and grepping for the symbol or message text.
- Category tags: splitting, filtering, page-ops, review/QC, navigation, selection, undo, search,
  display/zoom, settings, feedback, accessibility, performance.
- Tab keys come from `ui/actions.py` (`SPECS`, context "kontrol" plus "app"). Keys marked yerel are
  handled by the timeline widget, not by a registry action.

## Observations

Each of these is an observation, not a decision. "Verified" means checked by running the core on a small
synthetic job or by reading the code path; nothing was verified in a running window.

- O-01 (observation) Only one filter kind exists and it is applied to a selection. No filter selects pages by
  content (QR text, blank, size, orientation, OCR text). `docs/ui-goal/feature-ideas.md` items 1 to 7 list these
  as ideas. Evidence: K-21 to K-30.
- O-02 (observation) There is no "remove filter", "remove template", "restore empty page" or "turn on drop
  empty" command in the window, although the core or CLI has the last three (`cli/jobs.py:remove_template,
  empty_pages`). Evidence: K-20, K-28, K-52.
- O-03 (observation) K on the first page of a job changes its label from "İşin başı" to "Elle kesim" without
  splitting anything. Verified: `cut_kinds` returns `{'a/0': 'manual'}` after `add_cut('a/0')`. K on the first page
  after a QR separator adds a manual cut that is hidden behind the "qr" label (verified: kinds stay `qr`), so the
  history row says "Kesim eklendi" and nothing visible changes. Re-checked 2026-11-19 against the code: `toggle_cut` still has no guard for page 1; the ledger tracks it as B-020 (S3, open, strict xfail test).
- O-04 (observation) M on a QR-started document that also had a hidden manual cut removed only the QR cut; the
  document stays split (verified with the core: after `remove_cut` of the separator the kinds become
  `manual` and the two documents remain), yet the toast said "Belge N, Belge N-1 ile birleştirildi."
  Evidence: `ui/kontrol.py:merge_current (L379-L405)`. Status 2026-11-19: no longer true at HEAD. cefd148 (ledger B-021)
  removes both cuts as one step and shows the toast only if the document count dropped; the earlier draft text above
  describes the state before that fix.
- O-05 (observation) Eleven status-line messages (K-114) use `window.message`, a plain `QLabel` with no
  accessible announcement and no clearing: grep of `ui/main_window.py` finds no `message.clear` or timer, so a
  message such as "Kontrol bekleyen belge yok." stays until another one replaces it. Similar information
  ("Kontrol gereken tek belge bu.", merge, delete) goes to a toast, which is announced. The two channels are mixed
  for the same kind of event. Ledger B-022 (S3, open, strict xfail test). Evidence: `ui/main_window.py (L531, L1170)`, `ui/feedback.py:announce (L36)`.
- O-06 (observation) A queued toast's "Geri al" calls `controller.undo`, which undoes the newest step on the stack,
  not the step the toast was about. Toasts queue (one visible at a time, 6 s each), so a stale one can undo the
  wrong edit. Status 2026-11-19: fixed in cefd148 (ledger B-023). `feedback.undo_last` ties each Geri al to the step it
  was made for and hides the action once another step exists; two passing tests in `test_ledger_a.py`. Evidence: `ui/kontrol.py:_toast (L225-L232)`, `ui/feedback.py:Toaster.show, _next (L157, L181)`.
- O-07 (observation) A thumbnail that fails to render (`except Exception: image = None`) leaves the tile at
  "Yükleniyor" forever, and the loupe falls back to a blank paper rectangle when the PDF cannot be read. Neither
  says the page could not be shown, which sits against PRODUCT.md "Never silent". Ledger B-024 (S3, open, strict xfail test). Evidence:
  `ui/thumbnails.py:_render (L165-L168)`, `ui/kontrol.py:_render_page (L581-L589)`.
- O-08 (observation) Approving a document does not clear its Kontrol rider or remove it from N / Shift+N. A

  (L452)` (uses all check rows). Ledger B-025 (S4, open, no test).

  `lambda _n: self.show_tab("degerler")`, so the number is dropped. Whether Değerler then shows that document: the ledger says it does not (B-012, S3, open, strict xfail
  test in `test_ledger_c.py`); not run here. Evidence: `ui/main_window.py:_job_opened (L1153)`.
- O-10 (observation) Ctrl+F on Kontrol opens "Belgeye veya sayfaya git", while the menu item reads "Bul…". There is

  Kontrol and Değerler route it (`connect_tab("app.git", ...)` in `kontrol_actions.py` and `degerler.py:310`). Ledger B-026 (menu name) and B-027 (Ctrl+G routing), both S4 and open.
