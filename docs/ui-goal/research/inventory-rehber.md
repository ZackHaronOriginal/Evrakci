# Inventory: Rehber tab

Scope: everything a user can see or do on Rehber (the scanning guide, its search and contents list, and the printable QR separator sheet), plus the core it calls (`pipeline/separator.py`, `ui/rehber_print.py`) and the guide text itself (`docs/tarama-rehberi.md`). How separator pages are recognised at import is in `inventory-yukle.md` (Y-26).

Method: read from code and tests; nothing was run, no printer was used. "Tested?" names the test that asserts the behaviour; "none" means no test found by reading `tests/`. Turkish UI strings are quoted as in the code. Line numbers are from the checkout at commit 589522f.

Short names: `rehber.py` = `src/evrakci/ui/rehber.py`, `content` = `ui/rehber_content.py`, `reader` = `ui/rehber_reader.py`, `parts` = `ui/rehber_parts.py`, `print` = `ui/rehber_print.py`, `RT` = `tests/ui/test_rehber.py`, `G` = `tests/ui/test_export_guide.py`, `P4` = `tests/ui/test_phase4.py`.

Constants found: sheets per print 1 to 200 (`rehber_print.SHEETS`), spin box default 20, zoom 50 to 300 % in steps of 10 (`ZOOM_RANGE`), reading speed 180 words per minute for the "dakikalık okuma" line, text column at most 680 px (scaled by zoom and text size), PDF fallback names `ayirac-sayfalari.pdf` then `-2` to `-20`, search result announcement delayed 500 ms, side panel 368 px (440 at large text).

## Observations

These are observations, not decisions.

1. **"Kaç adet ... sayfa" counts sheets, but prints twice as many pages.** The box is labelled "sayfa" and the tooltip says "ayıraç sayfası sayısı", yet `print_separators` prints `2 * sheets` pages and the toast says "N ayıraç sayfası (2N sayfa)". The CLI help calls the same number "yaprak". The default is 20 in the window and 10 on the command line (cli/main.py:78 versus rehber.py:231). On a one-sided printer the user needs 2N sheets, and no option offers one-sided output.
2. **The user cannot see the sheet before printing.** The side panel has a spin box, a fixed paper label and a button; there is no preview of the QR page. No choice of paper size, sheet text or per-sheet content. Every sheet carries the same payload, so the idea in `feature-ideas.md` #1 (QR text such as a box number) has no hook yet in `separator.py`.
3. **The guide points to a control that is not in the window.** "Çift taraflı taramadaki boş arka yüzleri iş ayarından atabilirsiniz" refers to the job setting `drop_empty`, which only the CLI sets (`evrakci is bos-sayfalar`, cli/jobs.py:579); no screen calls `set_drop_empty`.
4. **The guide mixes staff and command-line advice.** Step 1 of "QR ayıraç sayfaları" shows `evrakci ayirac ayirac.pdf --adet 10`; PRODUCT.md says the users know the copier and Windows and nothing about programming. The key "Ctrl+P" is typed into the Markdown, while the shortcut table is generated from the registry, so the two can drift.
5. **The guide stops at "Yükleme".** It says nothing about drag and drop, Kontrol marks, Şablonlar, Değerler, the empty-folder rule of Dışa Aktar, or retention. It has no pictures and no sample of a separator sheet. It is a shipped file that a chamber cannot edit from the window, although PRODUCT.md calls the app "fully configurable".
6. **Weak links from the places a first-time user starts.** The empty Yükle page has no guide link (only the inspector with a job open has one, yukle_side.py:ProfileRows), and that link opens Rehber at the top rather than at "Tarayıcı ayarları".
7. **The PDF fallback leaves files behind.** `open_separators` writes into the app data folder, overwrites `ayirac-sayfalari.pdf` each time, and may leave up to 20 numbered copies; nothing deletes them and the screen never says where they are.
8. **Margins.** `prepare` sets all margins to 0 and each page is drawn stretched over the whole viewport. Whether a real printer with a non-printable edge clips the QR's quiet zone could not be verified without a printer (unclear). The PDF route does not have this question, but the user is not told which route is safer.
9. **Search is narrow by design.** It looks only inside the guide, one text block at a time, and says "Daha kısa bir sözcük deneyin" when a phrase fails. It does not search the shortcuts of other tabs or the app's commands (Ctrl+K does that).
10. **Packaging risk.** The guide is found only next to the installed program or in a source checkout; a normal wheel install would show "Rehber dosyası bulunamadı." (content:guide_text). The installer is tested to include it; any other package type is not.
11. **Not verified.** Printing on real hardware, the default context menu's language, and the sheet's look beyond the decoded QR were not run or viewed.
