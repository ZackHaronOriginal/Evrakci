# Inventory: Şablonlar tab

Research file, written from the code as it stands. Nothing here is a decision. "Observations" at the end lists things that look missing, inconsistent or awkward, each with its evidence.

Sources read: `src/evrakci/ui/sablon.py`, `sablon_canvas.py`, `sablon_nav.py`, `sablon_inspector.py`, `sablon_live.py`, `sablon_read.py`, `sablon_sync.py`, `sablon_rulers.py`, `sablon_empty.py`, `sablon_parts.py`, `actions.py`, `main_window.py` (wiring), `zoomview.py`; the core: `pipeline/templates/{model,store,read,values}.py`, `pipeline/naming.py`, `pipeline/review.py`, `pipeline/render.py`, `pipeline/ocr/{engine,tesseract}.py`, `cli/templates.py`. Tests read: `tests/ui/test_sablon.py`, `test_sablon_canvas.py`, `test_sablon_window.py`, `test_phase4.py`, and `tests/test_template_model.py`, `test_template_read.py`, `test_template_store.py`, `test_templates_review.py`, `test_templates_review2.py`, `test_cli_templates.py`, `test_cli_template_read.py`, `test_job_templates.py`.

Conventions. File names are under `src/evrakci/`. Line numbers are from the current files. Test paths are relative to `tests/`. "none" means no test found by reading and grepping. The suite was not run; one scratch probe on the Değerler tab is mentioned only in the Değerler file. Category tags are from the list in the task.

Vocabulary used by the code: a template has variables; each variable has sections (called "bölüm" in the list and "kutu" in the inspector and menus; a section after the first is a "variant"); the order of sections is the try order. The core "knows no fields, types or document kinds" (`pipeline/templates/model.py` header), so there are no variable types (S-17).

## Observations

Each item is an observation, not a decision.

- **O-01 Template management is command-line only.** The window can create a template and edit it, but there is no rename, delete, duplicate, import, export, threshold or keywords control (grep of `ui/` for `import_file`, `.export(`, `delete`, `set_min_confidence`, `keywords` finds none for templates). The README says templates are shared between PCs with `sablon disa-aktar` / `ice-aktar`; office staff in the window have no way to do it. A template cannot be renamed even from the command line.
- **O-02 Damaged template files vanish silently in the window.** `list()` is called without `on_error` (`sablon.py:354`, `main_window.py:1129`), so a template that cannot be read is missing from the list with no message; the CLI reports it. This is ledger B-017 (open), with a strict-xfail repro in `ui/test_ledger_c.py`.
- **O-03 Del removes a whole variable without asking, and its label says "Kutuyu sil".** On a variable row with two or more boxes (or none) Del deletes the variable and all boxes; only a toast with Geri al follows. A variable with exactly one box cannot be deleted in one step: its row stands for the box, so Del removes the box first (`sablon.py:delete_selected` 800-828, `sablon_nav.py:fill` 212-231). `docs/ui-goal/shortcuts.md` says Del acts "on the chosen variable when it has no box". Ledger B-015 (open) records the label. Since cefd148 the toast's Geri al only acts while this step is the newest (B-023, `feedback.py:undo_last`).
- **O-04 Kutu çiz stays on after each box.** `add_box` does not leave drawing mode, so a second drag adds another variant to the same variable instead of replacing the box (`sablon.py:740-754`); with the tool on, clicking an existing box starts a new rubber box instead of selecting. A drag of 2 mm or more is enough to add a box; smaller drags are dropped without a word (`sablon_canvas.py:607`).
- **O-05 "Izgaraya oturt" is a snap, not a grid.** No grid or guide lines are drawn; only the rulers show millimetres. The snap does not apply to the arrow nudge or to the X / Y / size fields, so a box can sit on 70,25 while snap is on (`sablon_canvas.py:462, 729`; `sablon_inspector.py:MmSpin`).
- **O-06 The inspector can put a box outside the sheet.** `_box_edited` calls `canvas.update_box` and stores the numbers without the canvas's clamp (`sablon.py:758-764`; `sablon_canvas.py:_clamp` is used by drag, resize and the keyboard box, not by the inspector), and the field ranges (X to sheet minus 2, width to the sheet) allow X plus width beyond the edge. The reader then clips the box (S-22, `mm_box_to_pixels`). Ledger B-016 (open) with a strict-xfail repro.
- **O-07 Variant look.** The badge shows the variable's number, so all variants of one variable carry the same number and differ only by a dashed outline, and the dashes also mean "drawn on another example". Whether a box counts as "another example" depends on the string "{iş adı} · Belge N · s.P" (`sablon.py:_example_name`), so renaming the job, or cutting the job so that a document's first page moves, makes old boxes look dashed (`sablon.py:734`).
- **O-08 Live-read cost is unmeasured but structural.** Each change re-reads the whole example document with every variable of the template (one Tesseract process per box, 300 dpi page render), `default_engine()` builds a new engine for every read, so its availability check (`tesseract --list-langs`) runs again each time (`sablon_live.py:_engine` 19-24, `tesseract.py:available` 364). Nudging a box with the arrow keys triggers it 400 ms after the last key.
- **O-09 Bütün örneklerde dene reads every document, and can only be stopped with Esc.** It does not offer a choice of examples, includes documents of other kinds, and has no stop button or Ctrl+Period (the "durdur" key used on the other tabs); the command is disabled while it runs and progress appears only as status text (`sablon_live.py:112-137`, `actions.py` has no `sablonlar.durdur`).
- **O-10 Try-all results do not outlive the screen state.** The marks "· N kontrol" live in memory, are dropped when another template or job is opened (`sablon.py:open_template` 398, `_refresh_examples` 613), are not shared with Değerler, and the tab has no "next example that needs a check" key (no N/Shift+N here).
- **O-11 No view of which documents use the template.** Applying a template is done in Kontrol; this tab never shows which documents carry it or how many, and cannot apply it.
- **O-12 Page numbers.** The page field allows up to 999 whatever the document length and a box on a missing page is noticed only after a read ("sayfa yok" note). Only "first-based" and "last" are possible; there is no "second to last". Typing 0 becomes 1 without a message (`sablon_inspector.py:PageSpin.valueFromText`).
- **O-13 The threshold is invisible but decides labels.** `level_of` uses the template's `min_confidence` to label reads "Kontrol" or not, yet the number is not shown or editable anywhere in the window (S-10, `sablon_live.py:_minimum`).
- **O-14 Names are case-sensitive and may contain spaces.** "Firma" and "firma" are two variables; the field hint suggests "Firma_Adi", Değerler turns "_" into a space for column titles, and the README example uses "Firma Ünvanı" with a space. Evidence: `templates/model.py:_has` (123), `degerler_model.py:display_name` (55).
- **O-15 Shared template files carry the job name.** `template_to_dict` writes each section's `example` label ("{iş adı} · Belge N · s.P"), so an exported template file includes the name of the job it was drawn on (`templates/model.py:template_to_dict` 221, `sablon.py:_example_name`). Whether job names can identify people was not checked. Ledger B-019 (open) with a strict-xfail repro in `ui/test_ledger_c.py`.
- **O-16 Dead helpers in the screen.** `LiveReads.read_lines` / `reads_text` and `sablon_read.lines` are not shown anywhere (tests only), and `toggle_draw`, `toggle_grid`, `move_selected_section` have no caller in `ui/` (grep).
- **O-17 Empty names are silent.** The name dialogs return nothing for a blank name or Vazgeç and the screen shows no message (`sablon.py:_ask_text` 373-381).
- **O-18 Undo history is lost on switching templates.** `open_template` clears the stack (`sablon.py:394`); a user who clicks another template cannot undo the last edit of the first one. The edit itself is already saved.
- **O-19 Untested by reading `tests/`:** Ctrl+F in the list, a real mouse drag in the variable list, text typed into the page spin, the dialogs (replaced in tests), the empty-name case, the "Okunuyor…" state, "Okumaları sayfada göster" painting content, the third item of the page context menu, the status-bar flagged count, render failure text, engine failure text on this tab, and the hand-off from Değerler (S-30).
- **O-20 A reading in Şablonlar is not the value in Değerler.** The live and try-all reads use the same reader but are not stored; the first time the numbers meet the real job is "Değerleri oku" in Değerler. A user who changes the template after reading sees the Değerler values go stale only by the "yalnızca eksikleri oku" rule (S-11).
- **O-21 The tab opens on the first template by name, not the last one used.** `refresh_templates` opens row 0 when nothing is open and the choice is not saved anywhere (S-86, S-87), so a user with several templates lands on the same one after every restart. Evidence: `sablon.py:refresh_templates` (352-371).
- **O-22 A failed template save is told in two small places.** The message sits in the left column and the status bar says "Şablon kaydedilemedi"; there is no toast, no retry button beside the save state and no announcement of the left-column text, whereas a failed job save (B-029, fixed in cefd148) shows a "Kaydedilemedi" state with "Yeniden dene" in the title band and an error toast. Evidence: `sablon.py:_flush_save` (966-980) against `main_window.py:_save_failed` (1237) and `feedback.py:SaveState.set_failed` (358). Not run on a full disk.
- **O-23 Dead or unreachable guards.** `move_selected_section` and its message have no caller in `ui/`, and the "Denemek için bir şablon ve açık bir iş gerekir." guard cannot be reached through the window because the command is disabled (S-88). Evidence: grep of `ui/`.
