# Shortcut checklist (by hand)

For the owner, on a real PC with a Turkish Q keyboard and a demo job (Yükle > Dosya ekle…, or any job of a few documents). One line per contract row: key, tab, what to do, what you should see. Tick the last column. A row marked with an M-number is known to differ today (see `shortcut-mismatches.md`); write down what you saw instead.

319 rows. Keys are grouped; inside a group the order is Yükle, Kontrol, Şablonlar, Değerler, Dışa Aktar, Rehber.
