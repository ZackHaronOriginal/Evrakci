Python runtime
--------------
Python (python3*.dll and the modules in lib\): PSF-2.0. Python-LICENSE.txt is Python's own
licence file; it also carries the notices of the libraries built into Python (expat, zlib,
libffi, bzip2, xz, mpdecimal, OpenSSL and others).

Windows only: the Microsoft Visual C++ runtime files (vcruntime140*.dll, msvcp140*.dll and
related) are redistributed under Microsoft's Visual C++ Redistributable licence terms, which
cx_Freeze places in share\licenses\.


Tesseract for Windows (tesseract\tesseract.exe)
------------------------------------------------
Built from source by vcpkg (pinned in packaging\vcpkg\vcpkg.json) as one static program,
without curl, libarchive or JBIG-KIT. The libraries built into it, each with its licence text
in tesseract\licenses\<name>.txt:

  tesseract        Apache-2.0
  leptonica        BSD-2-Clause
  cpu-features     Apache-2.0
  giflib           MIT
  libjpeg-turbo    IJG, BSD-3-Clause and Zlib. This software is based in part on the work of
                   the Independent JPEG Group.
  libpng           libpng-2.0
  libspng          BSD-2-Clause
  libwebp          BSD-3-Clause
  openjpeg         BSD-2-Clause
  tiff (libtiff)   libtiff (BSD-style)

On Linux, Tesseract is not bundled (it comes from the system package); only its small output
config files (configs\, tessconfigs\, Apache-2.0) and English data for Tesseract 4 are in
tessdata_best\.

(libpng), libjpeg (IJG), md4c (MIT), pcre2 (BSD-3-Clause), zlib (Zlib), tinycbor (MIT) and the

licence (licenses\linux\ICU.txt). The complete list with every licence text is at

Left out on purpose
-------------------
GPL-only parts never ship: GNU Readline, GDBM, JBIG-KIT, Qt Virtual Keyboard and Qt Wayland
Compositor. Qt's PDF module (Qt Pdf and its image plugin) is not used and is removed. The
build fails if any GPL-only part remains. Ghostscript, PyMuPDF and PyQt are not used and not
included.


Source code
-----------
Qt / PySide6 source (LGPL): the exact PySide6 version is listed in VERSIONS.txt. Its source is
available from https://download.qt.io/official_releases/QtForPython/ and
https://pypi.org/project/PySide6/ (source distribution). img2pdf and fpdf2 (LGPL-3.0) are
plain Python files in lib\; their source is the files themselves and https://pypi.org. For at
least three years, the Evrakçı maintainer also provides the source of every LGPL part listed
here on written request. To use your own Qt build, replace the files in lib\PySide6\ with a
compatible build.
